# STAHL — Service Intervals

Per STAHL ST Series Operating & Maintenance Instructions and STAHL ST brochure 2107.

Intervals **shorten** under: heavy duty, multi-shift, dusty / hot / corrosive environment, outdoor use.

---

## Daily — operator (pre-shift)

| Item | Check |
|---|---|
| Nameplate | Legible (model, SWL, serial, year, FEM) |
| Visual | No cracks, dents, oil leaks, loose fasteners, corrosion |
| Pendant | Cable + casing intact, no exposed conductors, strain wire fitted |
| E-stop | Latches when pressed, releases on twist, kills every motion |
| Direction | Up/down match pendant labels |
| Brake | Brief lift/lower cycle — clean engagement, no creep on stop |
| Hook + safety latch | Latch closes fully under spring; no visible damage |
| Chain | Visible lubrication; no obvious twist or distortion |
| Limit switches | Both ends — motion stops at intended position |

---

## 3-Monthly — preventive maintenance

Estimated time: ~45 minutes.

| Item | Check / Measure |
|---|---|
| Pre-start visual | Damage, fasteners, leaks |
| Chain | Cleaned + re-lubricated (Ceplattyn / SKD 3000 for food / medical) |
| Chain — 11-link wear | Measure with gauge 14 320 00 65 0 — see [01_measurements.md](01_measurements.md) |
| Chain — twist | Welds outwards over sprocket |
| Chain anchorage | Suspension bolt secure; never turn-and-refit a used bolt |
| Chain stopper | In place; min free chain X met (see model spec) |
| Load hook | h ≥ h_min, z ≤ z_max for actual reeving |
| Suspension hook | h ≥ h_min, z ≤ z_max |
| Hook safety latch | Closes fully under spring |
| Hook block | No cracks; smooth swivel |
| Brake — function | Hold under rated load; max slip 100 mm (ceiling, not target) |
| Brake — wear | ST05 displacement S; ST10+ air gap with feeler gauge |
| Slip clutch | No-load test: slip max 3 sec at end stop, motor rotating, chain still |
| Lubrication | Gear oil level / grease condition |
| Pendant | Strain wire, all functions, E-stop kills every motion |
| Limit switches | Function check — both ends stop at intended position |
| Trolley wheels | Wear ≤ 5% Ø reduction |
| Runway | Level, end stops fitted, no contamination |
| Sign-off | Functional test with rated load; service log entry |

## Annual — competent person (LOLER thorough examination)

Estimated time: ~90 minutes.

In addition to all 3-monthly items:

### Documentation

- Manufacturer manual available
- Previous examination report reviewed for raised defects
- Chain certificate on record (Grade 8 per DIN 5684, safety factor > 5.0)
- Scope of examination confirmed with duty holder

### Configuration verification

- Reeving (1/1 or 2/1) matches nameplate
- No unauthorised modifications (no welding, drilling, non-STAHL parts)
- FEM duty class suitable for actual application
- Hoist suitable for lifting task (not pulling at angle, towing, person-lifting)

### Environmental

- IP55 suitable for site environment
- Operating temp within −20 to +40 °C
- No corrosive / contaminated environment

### Structural & suspension (detailed)

- Suspension point integrity — no cracks / distortion
- Main housing — cast-iron chain guide critical (load path)
- Structural fasteners torqued — see [01_measurements.md](01_measurements.md)

### Chain (detailed)

- 11-link measurement recorded
- Individual link inspection (cracks, corrosion, weld defects, impact, elongation)
- Heat damage check (bluing, straightened/twisted links)
- Chain anchorage — out-of-service inspection of suspension bolt

### Hooks (detailed)

- Load hook 1/1 dimensional check, recorded
- Load hook 2/1 (if fitted) dimensional check, recorded
- Suspension hook dimensional check, recorded
- Hook crack inspection (throat, saddle, neck) — NDT at competent person discretion
- Swivel test under load — binding indicates pin/thrust bearing wear
- Safety latch full travel + spring tension

### Brake — comprehensive

- Brake test with rated load (max 100 mm slip)
- Brake wear measurement (ST05 shim displacement, ST10+ air gap)
- Brake internals visual — lining, disc, dust contamination, thermal damage

### Slip clutch — competent test

- No-load function test (slip max 3 sec)
- Confirm clutch hasn't been used routinely as end-stop (lining wear pattern)
- Annual function test with 1.25× rated load — must just lift; rated load must hold every position
- **Verify crane / runway / building structure supports 1.25× SWL test load before testing**

### Electrical

- Earth continuity to all exposed metalwork (record reading; typical < 0.5 Ω)
- Insulation resistance test — phase-to-phase + phase-to-earth, control + motor, 500V DC, > 1 MΩ
- Pendant — every function + E-stop overrides every motion + interlock logic + direction reversal
- Operational limit switches — function + position
- Emergency (ultimate) limits — fitted and functional
- Lockable main isolator — required, all-pole disconnect
- Phase monitoring relay (if fitted) — test by phase swap

### Trolley & runway

- Wheel wear measured at unworn reference — replace at 5% Ø reduction
- Flange wear pattern — note if uneven (canting indicator)
- Trolley drive — both speeds, both directions, brake performance
- Runway — level, straight, end stops engaged before chain hoist contacts ends

### Functional verification

- Rated load lift test — full hook path
- Dynamic test 125% SWL — only if structure supports + duty holder specifies

### Service life (FEM 9.755)

- Operating hours read (if counter fitted) — record
- Calculate life consumed vs theoretical → remaining safe working period
- If SWP expired → general overhaul required

### Report & certification

- Report of Thorough Examination issued (LOLER Reg 10, within 28 days)
- Next examination date set (12 months equipment / 6 months accessories or person-lifting)
- Defects clearly communicated; serious/imminent defects → out of service until rectified

## 5-Year — oil change + deep service

Estimated time: ~60 minutes (above ST05 which is grease only).

| Item | Detail |
|---|---|
| Preparation | Isolate, lock off, run hoist briefly to warm oil, remove load |
| Drain | Remove vent screw sticker (first service), open air vent, drain — capacity per [01_measurements.md](01_measurements.md) |
| Inspect drained oil | Metal particles → gear wear; water → seal issue; dark/burnt → overheat |
| Magnetic plug | Fine fuzz normal; chunks investigate |
| Refill | Correct ISO VG 460 spec; measure quantity (do not "fill to level") |
| Cold-temp option | Shell Tivela WB for −40 °C operation |
| Copper gaskets | Replace on every plug — single-use |
| Plug torque | 10 Nm (cast housing — do not over-torque) |
| Air vent / breather | Clean, not blocked |
| All grease points | Trolley + ST05 motor bearing (~50 g GOOF) |
| Chain | Full clean + re-lube (old lube can turn abrasive when trapping swarf) |
| Pendant cable | Inspect at flex points (cable glands) |
| Electrical terminals | Re-torque to STAHL spec |
| Brake | Air gap / displacement measured — natural overhaul point |
| Clutch | Setting verified |
| Service life calc | If approaching SWP, plan general overhaul |

---

## End of theoretical service life — General Overhaul

When operating-hour counter shows life consumed = full FEM-class theoretical hours OR no counter fitted and 10 years from commissioning. Done by manufacturer or authorised specialist. Entry in test booklet for continued operation.

Components typically replaced:
- Brake assembly
- Friction clutch
- Bearings, seals
- Gear oil + cover seal
- Suspension fasteners
- Connection elements

After GO, inspector determines new theoretical operating time and next GO interval.

---

## Conditions that **shorten** intervals

- Multi-shift / continuous duty
- Dust ingress / abrasive environment
- Outdoor or corrosive atmosphere
- High ambient temperature
- Cold-store operation (lubricant grade matters)
- Frequent overload events (slip clutch activated repeatedly)
- Application change (e.g. converting reference from intermittent to continuous duty)
